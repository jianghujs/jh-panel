# 主备管理插件本地版方案

## 目标

- 插件只负责本机侧的主备切换与状态展示
- 支持分步执行、暂停、继续、异常提示和日志查看
- 支持主机、备机两种角色切换流程
- 支持自检状态展示和手动修复指引

## 功能介绍

- `总览`：用于展示本机当前角色、目标角色、切换状态、自检状态和云监控配置，提供快速操作入口。
- `切换角色`：用于把当前机器切换为主机或备机，按插件配置的步骤分阶段执行，支持每一步的单独执行，支持流程代码编辑，提供异常处理提示文档。
- `关闭服务入口`：用于快速关闭当前机器的对外入口服务，主要是停止 OpenResty，避免故障或切换过程中继续承载流量。
- `自检状态`：用于集中展示本机各检查项的当前结果，异常时帮助运维判断需要处理的服务或任务。
- `操作日志`：用于查看本机最近的操作记录和切换过程，方便排查执行结果和异常原因。

## 数据流程

### 对外服务控制

1. 总览页根据 `external_closed` 显示对外服务状态

2. 当 `external_closed=false` 时，按钮显示“关闭对外服务”

3. 用户点击“关闭对外服务”后，插件停止 OpenResty，并更新：

   - `external_closed=true`
   - `status_text=关闭对外服务完成：OpenResty 已停止`

4. 当 `external_closed=true` 时，按钮显示“打开对外服务”

5. 用户点击“打开对外服务”后，插件启动 OpenResty，并更新：

   - `external_closed=false`
   - `status_text=打开对外服务完成：OpenResty 已启动`

6. 对外服务状态变化后，插件同步刷新总览页和自检状态

### 角色切换

1. 用户点击“切换角色”

2. 插件弹出角色选择界面，选择 `master` 或 `standby`

3. 插件生成本地切换任务文件

   `/www/server/ha_manager_local/data/switch_tasks/TASK_xxx.json`

4. 插件根据 `flow_config.json` 加载对应角色的步骤

5. 用户点击“继续执行”后，插件从当前阶段第一个未完成的必选步骤开始执行

6. 每个步骤执行时更新：

   - `run_state`
   - `status`
   - `status_text`
   - `current_stage_title`
   - `current_step`
   - `next_step`
   - `steps[].state`

7. 步骤完成后记录：

   - `steps[].finished_at`
   - `steps[].logs`
   - 切换日志文件

8. 步骤失败后记录：

   - `run_state=failed`
   - `status=danger`
   - `last_error`
   - 当前步骤日志

9. 用户点击暂停后，任务进入 `paused`

10. 切换为主机时按顺序执行：

    - 主机预上线
    - 等待备机下线
    - 主机正式上线

11. 切换为备机时执行：

    - 备机下线

    备机只有一个流程，切换弹框顶部不显示阶段步骤条

12. 切换完成后更新：

    - `role`
    - `desired_role`
    - `run_state=success`
    - `status=normal`
    - `status_text=状态正常`

### 绑定信息

1. 插件提供本机 ID：`host_id`

2. 用户填写或修改本机信息后保存到 `state.json`

3. 绑定信息只用于本机侧展示和后续扩展，不写入云监控相关逻辑

### 自检状态

1. 插件展示自检结果

2. 自检项包括：

   - MySQL
   - OpenResty
   - rsync
   - 计划任务
   - 角色标记

3. 自检异常时给出处理指引和常用命令

## 接口设计

- `get_state`：获取本机当前角色、目标角色、切换状态、自检状态和云监控配置，用于页面初始化和刷新展示。
- `start_switch`：创建一次角色切换任务，传入目标角色后生成本地切换任务并进入执行流程。
- `read_switch_log`：按任务 ID 和偏移量读取切换日志，用于页面滚动查看执行过程。
- `health_check`：执行本机自检，刷新 OpenResty、rsync、计划任务和角色标记等结果。
- `title_state`：返回插件标题栏或列表状态所需的简要状态信息。


## 字段取值约定

`role`：`master`、`standby`、`unknown`

`status`：`normal`、`warning`、`danger`、`switching`、`unknown`

`run_state`：`idle`、`pending`、`running`、`paused`、`waiting_peer`、`failed`、`success`、`cancelled`

`steps[].state`：`pending`、`running`、`done`、`failed`、`skipped`

`health.health_status`：`normal`、`warning`、`danger`、`unknown`

`online_status`：`online`、`offline`、`unknown`

`collect_status`：`success`、`failed`、`partial`、`unknown`

`log_level`：`info`、`warning`、`error`

## 最终边界

主备管理插件只负责本机切换、自检、日志、异常提示和状态展示。

插件不包含云监控相关数据表、接口和同步逻辑。
