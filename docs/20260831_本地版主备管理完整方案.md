# 本地版主备管理完整方案

## 目标

- 主备管理插件负责：当前主机的角色切换流程、自检、日志
- 云监控负责：主备关系展示、主机状态展示、切换任务展示、执行日志查看

## 数据流程

### 主备管理插件-本地切换

1. 用户点击“切换角色”

2. 插件弹出角色选择界面，用户选择 `master` 或 `standby`

3. 插件生成本地切换任务文件

   `/www/server/ha_manager_local/data/switch_tasks/TASK_xxx.json`

4. 插件加载对应角色的流程步骤

5. 每个步骤开始执行时，插件更新：

   - `run_state`
   - `status`
   - `status_text`
   - `current_stage_title`
   - `current_step`
   - `next_step`
   - `steps[].state`

6. 每个步骤执行完成后，插件写入：

   - `steps[].state=done`
   - `steps[].finished_at`
   - `steps[].logs`
   - 本地切换日志

7. 如果步骤失败，插件写入：

   - `run_state=failed`
   - `status=danger`
   - `status_text`
   - `last_error`
   - 当前步骤日志

8. 如果用户暂停，插件写入：

   - `run_state=paused`
   - `status_text=已暂停`

9. 如果切换为主机，流程按顺序执行：

    - 主机预上线
    - 等待备机下线
    - 主机正式上线

10. 如果切换为备机，流程执行：

    - 备机下线

11. 切换完成后，插件更新本机角色和状态：

    - `role`
    - `desired_role`
    - `run_state=success`
    - `status=normal`
    - `status_text=状态正常`

### 主备管理插件-绑定云监控

1. 用户打开“绑定云监控”页面

2. 页面展示本机 ID：`host_id`

3. 用户填写主备关系 ID：`pair_id`

4. 用户填写云监控地址：`url`

5. 用户点击保存

6. 插件把绑定信息写入：

   `/www/server/ha_manager_local/data/state.json`

7. 如果后端注册接口可用，插件向云监控提交本机绑定信息

8. 云监控根据 `pair_id` 判断主备关系是否存在

9. 如果 `pair_id` 不存在，云监控创建 `ha_pair`

10. 如果 `pair_id` 已存在，云监控更新或插入 `ha_host_state`

### 主备管理插件-状态上报云监控

1. 插件触发状态上报

2. 触发时机包括：

   - 插件初始化
   - 自检完成
   - 切换步骤开始
   - 切换步骤完成
   - 切换暂停
   - 切换失败
   - 切换取消
   - 切换完成
   - 定时上报

3. 插件读取：

   - `/www/server/ha_manager_local/data/state.json`
   - 当前 `switch_task` 文件
   - 当前自检结果
   - 当前日志路径

4. 插件组装上报数据

5. 插件请求云监控状态上报接口

   `POST /ha/api/local/report`

6. 云监控更新 `ha_host_state`

7. 云监控根据全部主机状态重新计算 `ha_pair.status`

8. 云监控根据最新状态写入 `ha_pair.status_text`

9. 云监控把切换任务写入 `ha_switch_task`

10. 云监控把日志追加写入：

    `/www/server/jh-monitor/logs/ha_switch/TASK_xxx.log`

11. 云监控列表页展示最新状态

### 云监控-主备列表展示

1. 云监控读取 `ha_pair`

2. 云监控读取同一个 `pair_id` 下的 `ha_host_state`

3. 云监控读取对应的 `ha_switch_task`

4. 云监控根据 `ha_switch_task.log_path` 读取日志文件

5. 如果有主机正在切换，列表展示：

   `主机名 + current_step`

6. 如果有主机等待对方操作，列表展示：

   `主机名 + status_text`

7. 如果有主机切换失败，列表展示：

   `主机名 + last_error`

8. 如果存在双主，列表展示：

   `双主异常`

9. 如果存在双备或无主，列表展示：

   `双备或无主异常`

10. 如果存在自检异常，列表展示：

    `主机名 + 自检异常`

11. 如果全部正常，列表展示：

    `状态正常`

12. 云监控可以打开切换任务详情，并查看对应日志

## 接口设计

### 绑定或注册本机

```http
POST /ha/api/local/register
```

请求：

```jsonc
{
  "pair_id": "HA_GROUP_001",
  "host_id": "HOST_A",
  "host_name": "主机A",
  "host_ip": "192.168.1.10",
  "role": "standby"
}
```

返回：

```jsonc
{
  "status": true,
  "msg": "注册成功",
  "data": {
    "pair_id": "HA_GROUP_001",
    "host_id": "HOST_A",
    "api_secret": ""
  }
}
```

### 拉取日志

```http
GET /ha/api/local/switch_log?switch_task_id=TASK_20260831_100000_A1B2C3&offset=0
```

返回：

```jsonc
{
  "status": true,
  "data": {
    "switch_task_id": "TASK_20260831_100000_A1B2C3",
    "log_path": "/www/server/jh-monitor/logs/ha_switch/TASK_20260831_100000_A1B2C3.log",

    "next_offset": 92
  }

```

## 字段取值约定

`role`：

- `master`
- `standby`
- `unknown`

`status` / `ha_pair.status`：

- `normal`
- `warning`
- `danger`
- `switching`
- `unknown`

`run_state` / `switch_status`：

- `idle`
- `pending`
- `running`
- `paused`
- `waiting_peer`
- `failed`
- `success`
- `cancelled`

`steps[].state`：

- `pending`
- `running`
- `done`
- `failed`
- `skipped`

`health_status`：

- `normal`
- `warning`
- `danger`
- `unknown`

`online_status`：

- `online`
- `offline`
- `unknown`

`collect_status`：

- `success`
- `failed`
- `partial`
- `unknown`

`log_level`：

- `info`
- `warning`
- `error`

## 最终边界

主备管理插件负责执行。

云监控负责展示。

云监控不提供切换角色按钮。

云监控不创建切换任务。

云监控不下发任务。

云监控不控制步骤继续、暂停、取消。

云监控接收插件上报的 `switch_task`、日志、状态，并展示当前状态和执行过程。

云监控切换日志存储到 `/www/server/jh-monitor/logs/ha_switch`，不写入 SQLite。
