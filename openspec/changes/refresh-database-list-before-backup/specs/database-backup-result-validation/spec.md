## ADDED Requirements

### Requirement: 导出及封装全部成功才视为备份成功

数据库备份 SHALL 同时确认导出和压缩/打包工具退出成功，并检查最终文件存在且非零；MUST NOT 仅以文件存在、压缩头存在或文件大小非零判定成功。管道执行 SHALL 传递导出与压缩各阶段失败。

#### Scenario: mysqldump 失败但 zstd 生成非零文件

- **WHEN** `mysqldump` 非零退出，`zstd` 仍产生非零输出
- **THEN** 本次备份失败，不写成功记录或运行该库历史清理

#### Scenario: pg_dump 失败但 gzip 生成非零文件

- **WHEN** `pg_dump` 非零退出，gzip 仍产生压缩头文件
- **THEN** 本次备份失败，不打印成功或登记成功记录

#### Scenario: mydumper 导出失败

- **WHEN** `mydumper` 非零退出
- **THEN** 不继续将失败目录打包为成功备份

#### Scenario: 打包或压缩失败

- **WHEN** 导出成功但 tar、zstd 或 gzip 失败
- **THEN** 本次备份失败，不登记成功记录或清理该库历史

#### Scenario: 合法空业务库

- **WHEN** 业务库没有用户表，但导出、封装及最终文件检查均成功
- **THEN** 系统允许该库备份成功，不因表数量为零误判失败

### Requirement: 失败产物只清理本次创建的内容

系统 SHALL 使用本次独占的临时产物，成功后发布为现有备份格式；失败时仅删除本次创建的不完整产物及临时目录，不覆盖或删除已有可用备份。日志 SHALL 提供类型、库名及失败阶段，不泄露凭据。

#### Scenario: 导出后半途失败

- **WHEN** 本次执行产生部分文件后失败
- **THEN** 系统清理本次不完整文件及临时目录，保留以前的所有可用备份

#### Scenario: 完整产物生成但登记失败

- **WHEN** 导出与封装成功，但写入 `backup` 表失败
- **THEN** 保留完整产物，日志说明文件位置和登记失败
- **AND** 命令返回失败，不运行该库历史清理

### Requirement: 命令正确汇总数据库备份失败

全部备份 SHALL 在同引擎内继续处理其他目标并汇总成功和失败数量，任一目标失败则命令非零退出。双引擎任务 SHALL 保留现有先 MySQL 后 PostgreSQL、首个引擎命令失败即停止的策略，不将部分完成显示为全部成功。

#### Scenario: 单个库备份失败

- **WHEN** 同引擎名单中的一个库失败而其他库可正常备份
- **THEN** 系统继续处理其他库，记录各库结果与汇总，最终非零退出

#### Scenario: 双引擎任务的第一个引擎失败

- **WHEN** MySQL 命令返回失败
- **THEN** 现有 `set -e` 生成脚本及旧 `database backupAll` 入口不继续执行 PostgreSQL
- **AND** 日志不声称双引擎全部成功

### Requirement: 历史清理隔离到本次成功的引擎和库

系统 SHALL 仅在本库新备份及成功记录写入后按原保留参数清理对应历史，不以本地 `pid` 作为唯一身份条件。候选历史 SHALL 同时匹配引擎、完整库名和现有文件格式，路径 SHALL 位于备份目录内。数据库命令 MUST NOT 在结束时清理整个共享备份目录。

#### Scenario: 两个插件的本地 ID 相同

- **WHEN** MySQL 和 PostgreSQL 库的本地 ID 相同，只有 MySQL 库本次成功
- **THEN** 清理仅作用于该 MySQL 库，PostgreSQL 历史文件和记录保持不变

#### Scenario: 名称含前缀或模式字符

- **WHEN** 备份库名为 `foo`，同时存在 `foo_bar` 及带百分号、下划线或通配符的合法库名
- **THEN** 身份判断按完整库名字面量及时间戳格式匹配，不清理其他库

#### Scenario: 兼容历史 MySQL 文件

- **WHEN** 当前 MySQL 库存在 `mysql_<db>_<timestamp>` 和旧 `db_<db>_<timestamp>` 格式的历史记录
- **THEN** 两类属于该库的历史均可按原保留规则处理

#### Scenario: 查询失败或空名单不清理共享目录

- **WHEN** 名单查询失败、引擎跳过、查询结果为空或指定库备份失败
- **THEN** 不运行该库或共享目录历史清理，其他库及引擎的历史备份保持不变

#### Scenario: 其他备份类型不受影响

- **WHEN** 执行网站、目录或插件配置备份
- **THEN** 保留其现有登记与清理行为，不使用数据库专用身份过滤规则
