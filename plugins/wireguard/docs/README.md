# WireGuard 插件使用与验证

## 手动验证清单
1. 进入“密钥初始化”，确认公钥/私钥为空时显示“生成密钥”。
2. 点击“生成密钥”，确认公钥/私钥内容展示，按钮变为“重新生成”。
3. 进入“配置列表”，点击“新增配置”，确认配置内容可编辑并保存为 `/etc/wireguard/<iface>.conf`。
4. 在“配置列表”点击“点对点配置向导”，填写对端信息并保存，确认配置文件自动创建。
5. 在“配置列表”执行“编辑/应用/删除”，确认配置可更新与生效。
6. 点击每个配置的“日志”，确认显示异常提示、配置摘要、运行 Peer、握手、路由、插件操作和最近 7 天系统服务日志；可刷新或复制日志。
7. 用测试配置验证“对端公钥等于本机公钥”“无 Peer”“配置尚未应用”等提示，确认日志中不包含私钥和预共享密钥。

## 注意事项
- 重新生成密钥会影响已存在的 WireGuard 配置，需确认后操作。
- 应用配置可能中断当前隧道连接，建议在维护窗口执行。
- “日志”是只读查询，不自动 ping、修改配置或重启服务。普通空闲连接握手较旧不一定表示故障，服务已启用也不代表已连通。
- 插件启用/停用/重启结果按配置保存在 `/www/server/wireguard/logs/<iface>.log`，从此功能上线后开始记录，单文件超过 128 KiB 时保留末尾约 64 KiB。手工执行的命令不在此记录范围内。
- 系统服务日志最多显示最近 7 天的 100 条；不通过 systemd 启动时可能没有记录。WireGuard 不会为每次握手失败输出详细原因。
- 日志会隐藏当前配置的私钥和预共享密钥，但保留公钥和网络地址，分享前请确认接收方可信。
